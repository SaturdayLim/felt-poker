## Key Decisions
- **Push to main after every finished set of work.** This is the owner's standing order, now in CLAUDE.md. Fast-forward `main` to the work branch. A push to `main` sometimes returns HTTP 500; a retry works.
- **CLAUDE.md is the source of truth for owner rules.** Every round adds or changes rule lines in it. Read it fully before any change.
- **Chips are the default unit.** Money appears only with Show money. Settle Up, payments, the share image and exports stay in money, because settling up is about money.
- **Tournaments are parked, not deleted** (`FEATURES.tournaments = false`). The code is kept for a later phase.
- **Sheets always slide up and down.** This replaced the earlier "pull out of the button" rule at the owner's request. Morphs clip and never stretch.
- **One CSS file per area for parallel agents:** `src/css/{nav,motion,players,chrome,review}.css`, loaded after `src/styles.css`. Agents own disjoint files.
- **Clash flags show late.** They appear only after a later hand is under way, so nobody learns about a hand in play. Red entries are left out of stats.
- **Viewer replay steps actions in time order** instead of pass columns. It is the owner's pick and is used in the viewer only; the host recorder still uses columns.
- **Alternatives rejected:** a white or ink text on #E64A19 (fails 4.5:1; #EE4E1C with ink text gives 4.6:1); a per-player hide eye (removed in 1.3.1 for dropdowns); a stretched view-transition morph (now clip, with `object-fit: none`).

## Known Issues & Pitfalls
- **Stop hook:** it demands commit and push whenever the tree is dirty. With background agents running, commit to the work branch as WIP; push to `main` only when the round is complete. CLAUDE.md says not to push while a question to the owner is open. The hook overrides that in practice; say so in the reply.
- **Parallel agents** share a working tree. Tell them which files they own, to re-read before each Edit, and not to commit. WIP commits by me may capture half-finished edits.
- **Dev data:** use `window.__store` (dev only). On the app, set `sessionStorage.setItem('felt-role','host')` first, or the Start view shows. Navigate with `location.hash`; `page.goto` to a new hash reloads before IndexedDB saves.
- **Headless Chromium** logs "Transition was aborted ... ViewTransition opt-in disabled" from `@view-transition`. It is harmless.
- **The old tab icon** still draws over the chip for a moment as a roll starts.
- **Bar charts with the new axis titles** were never seen with logged hand data.
- **"Check these cards" on hand 1 for Everett:** the owner reported it; the root cause was never proven. We now show the reason (board, shown, or another entry) and the colour.
- **Report canvas colours** (`src/report/canvas.ts`) still use the old Saturday teal skin.
- **Do not edit the generated files** `src/saturday/css/skin-felt.css` or `tokens.css` by hand. Edit `tokens.json` and rebuild.
